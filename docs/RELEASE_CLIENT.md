## Клиент для пользователей (PWDTT)

Рекомендуемый десктоп-клиент для Windows и Linux — скачайте **из этого релиза WDTT**:

| Файл | Платформа |
|------|-----------|
| `pwdtt-client-linux-amd64` | Linux x64 |
| `pwdtt-client-windows-amd64.exe` | Windows x64 |

Ссылку `wdtt://…` для подключения берите в панели (**Подключения** или **Пользователи**).
